# ITGC (IT General Controls) Audit Log Analyzer

An entry-level IS auditing application built with Python, PostgreSQL, Pandas, and Streamlit designed to parse database audit logs, detect security threats, and report on IT General Control violations.

## Quick Start with Docker
1. Ensure Docker and Docker Compose are installed.
2. Run:
   ```bash
   docker compose up --build
   ```
3. Open your browser at:
   **http://localhost:8501**
